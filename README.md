# Dattva – Brand Protection from AI Hallucinations
## Problem
AI models (ChatGPT, Perplexity, Gemini) frequently make false claims about brands. Brands have no
way to monitor or correct these errors.
## Solution
Dattva continuously monitors what all major AI models say about your brand, detects hallucinations,
and provides verified corrections + a "Verified Brand Profile" to reduce future errors.
## Demo
👉 **[Try the live hallucination audit →](https://dattva.com/hallucination)**
## How it works
1. Enter your brand domain
2. Dattva extracts ground truth from your website
3. Runs 50+ prompts across 4 LLMs
4. Flags any hallucination with correction
5. Generates llms.txt + schema to help AI cite you correctly
## Tech stack
- Vertex AI Agent Builder
- Gemini 2.5 Flash
- Discovery Engine
- OpenRouter (for multi-model access)
